# GoDigital — Design / Reverse Engineering v1

**Status: NOT STARTED**

This directory exists deliberately so the lifecycle is explicit.

Reverse Engineering v1 is still in STEP 0. The current artifacts recover what existed, what exists, what can be proven and what remains unknown. They do **not** decide what GoDigital should become.

DESIGN may begin only after owner review confirms or corrects the recovered product purpose and after the core canonicalization/security gates are sufficiently understood.

```text
RECOVERY asks: WHAT WAS / IS THERE?
DESIGN asks:   WHAT SHOULD WE BUILD?
```

No design artifact should silently reinterpret historical code as future intent.
